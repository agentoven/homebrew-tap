# Agentoven Tap

## How do I install these formulae?

`brew install agentoven/tap/<formula>`

Or `brew tap agentoven/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "agentoven/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
